# Support

- **Questions and problems:** [open an issue](https://github.com/RockxyApp/RockxyBase/issues/new/choose).
  Search the existing issues first — someone may already have asked.
- **Security vulnerabilities:** follow [SECURITY.md](SECURITY.md); never post them publicly.
- **Licences and purchases:** see [rockxy.io](https://rockxy.io).

Please include the RockxyBase version (RockxyBase ▸ About RockxyBase), your macOS version and
the database engine, and leave out passwords, connection strings, private hostnames and real
data.
